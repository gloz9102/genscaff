# Genscaff 2.2 Quick examples

[English](v2.2-quick-examples.md) | [한국어](v2.2-quick-examples.ko.md) | [README](../README.md)

These two samples were created at the user's explicit request for Genscaff 2.2 Quick. They share the fictional Yeoback workspace brand, CSS tokens, and standalone HTML structure. This demonstration does not change the normal Quick scope of narrow edits or establish comparative skill effectiveness.

## Dashboard

[Dashboard source](../examples/v2.2-quick/dashboard.html)

The operational view combines occupied seats, daily reservations, membership counts, seven-day occupancy, and room availability. Reservation filters update the visible rows and count. Each detail button opens a native dialog; Escape closes it and restores focus.

![Dashboard desktop](../examples/v2.2-quick/artifacts/dashboard-desktop.png)

## Landing page

[Landing source](../examples/v2.2-quick/landing.html)

The introduction, workspace options, and visit form are separate sections with deliberate whitespace. The primary link leads to workspace options. The form validates required fields and displays a local schedule preview. It sends no reservation or personal data to a backend.

![Landing desktop](../examples/v2.2-quick/artifacts/landing-desktop.png)

## Run and customize

From the repository root:

```shell
python -m http.server 8822 --bind 127.0.0.1 --directory examples/v2.2-quick
```

Open [dashboard](http://127.0.0.1:8822/dashboard.html) or [landing page](http://127.0.0.1:8822/landing.html). These URLs work only while the local server runs; they are not hosted demos.

Edit the `:root` tokens in [styles.css](../examples/v2.2-quick/styles.css) to replace the accent and its hover, pressed, foreground, and subtle variants. Recheck contrast after changing them. No frontend build or external asset download is needed to view the samples.

## Verified scope

The [verification script](../examples/v2.2-quick/verify.cjs) ran at 1440×1050 and 390×844 using the repository's existing Playwright installation. It checked page overflow, console/page errors, reservation filtering, dialog opening, Escape, focus restoration, section navigation, form results, and reduced-motion transition suppression. Screenshots were visually inspected, and mobile filter wrapping was corrected before rerunning checks.

```shell
node examples/v2.2-quick/verify.cjs
```

Verification requires Playwright and its Chromium runtime at the path used by the script; viewing the pages does not. See the [verification record](../examples/v2.2-quick/verification.md) and [captured artifacts](../examples/v2.2-quick/artifacts/).

All names and business data are fictional. Lighthouse, full keyboard auditing, assistive-technology testing, backend integration, and comparative A/B evaluation were not performed. These samples carry no Standard or Strict certification.
