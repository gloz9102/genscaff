## Usage rules

- Preserve the original aspect ratio and clear space.
- Use the light or transparent navy lockup on light backgrounds.
- Use the supplied dark-mode lockup on dark backgrounds; do not place the navy transparent lockup directly on dark navy.
- Do not stretch, rotate, recolor individual pieces, add effects, or separate the wordmark from the horizontal lockup.
- These files are raster deliverables. Reconstructing them as production SVGs requires a separate vector tracing and optical-cleanup pass.
