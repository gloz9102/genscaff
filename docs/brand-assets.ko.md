# Genscaff 브랜드 자산

[English](brand-assets.md) | [한국어](brand-assets.ko.md)

## 사용 규칙

- 원본 비율과 여백을 유지해 주세요.
- 라이트 배경에는 라이트 버전이나 네이비 투명 락업을 사용해 주세요.
- 다크 배경에는 제공된 다크모드 락업을 사용하고, 네이비 투명 락업을 짙은 네이비 위에 직접 놓지 마세요.
- 늘이기, 회전, 개별 요소 색상 변경, 효과 추가, 가로형 락업에서 워드마크 분리를 하지 마세요.
- 제공 파일은 래스터 결과물입니다. 프로덕션 SVG로 만들려면 별도의 벡터 트레이싱과 시각 보정이 필요합니다.
