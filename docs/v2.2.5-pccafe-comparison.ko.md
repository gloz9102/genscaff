# Genscaff v2.2.5 PC방 랜딩페이지 비교

[English](v2.2.5-pccafe-comparison.md) | [한국어 README](../README.ko.md)

가상의 LEVEL PC 라운지를 같은 브리프로 두 독립 에이전트가 제작했습니다. 한쪽만 Genscaff Standard를 적용했습니다. 이 페이지는 최종 보정된 샘플을 비교하며, 한 번의 결과로 스킬의 일반적인 우열을 판정하지 않습니다.

## 동일 조건

- 모델: 양쪽 모두 `gpt-5.6-luna`, 추론 수준 `xhigh`.
- 원본: 빈 개별 디렉터리, 같은 [브리프](../examples/v2.2.5-pccafe-comparison/brief.md), 같은 [imagegen 생성 이미지](../examples/v2.2.5-pccafe-comparison/assets/cafe-hero.png).
- 분리: 대화 이력 없이 시작한 두 에이전트에 서로의 소스와 결과 열람을 금지했습니다. 파일 접근을 기술적으로 차단한 샌드박스는 아닙니다.
- 처치: 적용군에만 Genscaff v2.2.5 Standard와 참조 문서를 제공했습니다. 미적용군에는 다른 프런트엔드 디자인 스킬도 적용하지 않았습니다.
- 검토: 부모 에이전트가 두 결과에 동일한 기능 검사를 수행하고, 실제 화면에서 발견한 접근성 및 줄바꿈 문제를 각 제작 에이전트에 전달했습니다. 미적 선호에 따른 재디자인은 하지 않았습니다.

## 확인한 차이와 보정

Standard는 호박색 포인트와 절제된 표면 구분을 사용하고, 요금 계산 아래에서 방문 계획을 인라인으로 확인합니다. 미적용 버전은 라임 포인트, 큰 기울임 강조, 공간별 색면을 사용하며 별도 모달에서 계획을 확인합니다. 둘 다 브리프의 핵심 기능을 구현했습니다.

Standard 최초 화면에서는 데스크톱 제목의 단어 분리와 닫힌 모바일 메뉴의 키보드 접근 상태를 보정해야 했습니다. Standard의 작은 보조 문구도 대비를 높였습니다. 미적용 최초 화면에서는 밝은 배경 위 강조 문구 대비가 각각 1.10:1, 2.41:1로 낮았습니다. 보정 후 6.19:1, 5.54:1을 확인했습니다. 모달 수정 시 모션 감소 설정에 맞춘 스크롤 동작도 확인했습니다.

이 보정은 최종 결과에 포함됩니다. 따라서 최종 스크린샷을 개입 없는 최초 생성 결과로 해석하면 안 됩니다. 기능 측면에서 한쪽이 우월하다고 결론 내리지 않습니다. 색상과 구성의 선호는 별도로 판단할 수 있습니다.

Standard의 [후보 A](../examples/v2.2.5-pccafe-comparison/standard/candidate-a-desktop.png), [후보 B](../examples/v2.2.5-pccafe-comparison/standard/candidate-b-desktop.png)와 [제작 기록](../examples/v2.2.5-pccafe-comparison/standard/contract.md)을 보존했습니다. 후보 캡처는 최종 페이지 제작 이후 보완되었으므로, 구현 전에 렌더 후보 선택을 완료했다는 증거로 취급하지 않습니다. [미적용 제작 기록](../examples/v2.2.5-pccafe-comparison/control/decisions.md)도 함께 제공합니다.

## 재현

| 공통 검사 | Standard 적용 | 미적용 |
|---|---|---|
| 데스크톱 및 모바일 이미지, 수평 넘침, 런타임 오류 | 통과 | 통과 |
| 각 환경의 요금 9개 조합, 확인 및 수정 | 통과 | 통과 |
| Tab → 방향키 선택 → Enter 확인 → 수정 | 통과 | 통과 |
| 확인 버튼 초점 가림, 호버 피드백 및 이탈 복원 | 통과 | 통과 |
| 터치 에뮬레이션 메뉴, 주요 링크, CSS 모션 감소 | 통과 | 통과 |

검사는 명시된 경로와 상태에 한정합니다. 모든 컨트롤의 접근성이나 모든 모바일 브라우저를 보증하지 않습니다.

보조 지표로 최종 HTML, CSS, JS는 양쪽 모두 3개 파일입니다. Standard는 33,792바이트와 503줄, 미적용은 37,813바이트와 370줄입니다. 공유 이미지, 검증 스크립트, 후보와 문서는 제외했습니다. 줄바꿈 방식에 영향을 받는 수치이며 품질 점수로 사용하지 않습니다.

저장소 루트에서 다음 서버를 실행합니다.

```shell
python -m http.server 8835 --bind 127.0.0.1 --directory examples/v2.2.5-pccafe-comparison
```

[비교 화면](http://127.0.0.1:8835/)에서 두 페이지를 엽니다. 정적 페이지이므로 빌드가 필요하지 않습니다.

브라우저 검증은 기존 release-audit의 Playwright 및 Chromium 런타임을 사용했습니다. 이 런타임이 설치된 환경에서 다음 명령으로 공통 검사를 실행할 수 있습니다.

```shell
node examples/v2.2.5-pccafe-comparison/verify.cjs
```

[공통 검사 원시 기록](../examples/v2.2.5-pccafe-comparison/artifacts/verification.json)에는 이미지 로딩, 수평 넘침, 좌석 3종 × 시간 3종 요금 계산, 확인과 수정, Tab 및 방향키와 Enter 경로, 초점 가림, 호버 및 포인터 이탈, 터치 메뉴, 모션 감소와 런타임 오류를 구분해 기록합니다.

실제 기기, 화면 읽기 프로그램, 전체 접근성 적합성, 사용자 선호 조사와 120회 릴리스 평가는 수행하지 않았습니다. 실제 매장, 예약, 결제와 연결되지 않습니다. [이미지 생성 도구와 프롬프트](../examples/v2.2.5-pccafe-comparison/assets/provenance.md)를 별도로 보존했습니다.
