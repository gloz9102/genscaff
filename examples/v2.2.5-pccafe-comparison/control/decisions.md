# LEVEL PC 라운지 control 디자인 및 검증 기록

## 디자인 결정

- 어두운 네이비와 라임 포인트를 기본으로 잡아 게임 공간의 집중감과 방문 계획 도구의 명확성을 함께 표현함.
- 제공된 `../assets/cafe-hero.png`만 히어로 시각 요소로 사용하고, 나머지 좌석 카드는 색상, 선, CSS 아이콘으로 구성함.
- 히어로에서 공간의 분위기를 먼저 보여준 다음 공간, 요금, 방문 계획을 순서대로 배치해 탐색 흐름을 만들었음.
- 요금 계산기는 좌석과 시간 선택을 좌우 영역으로 나눠 선택값과 예상 금액을 한눈에 확인하도록 설계함.
- 선택 확인은 실제 예약이나 결제가 아님을 계산기와 확인 대화상자에 반복 표기함.
- 모바일에서는 헤더 메뉴를 접고 좌석 선택을 세로 목록으로 바꿔 390px 화면에서 조작 가능하게 함.
- 외부 CDN을 사용하지 않고 시스템 글꼴만 사용함. 정적 파일만으로 동작함.
- `prefers-reduced-motion` 환경에서는 스크롤과 전환 애니메이션을 줄임.

## 접근성 보정

- 원래 밝은 인트로 배경(`#f2f1ec`) 위 라임 강조색(`#d9f268`)의 대비는 약 1.10:1로 낮았음. `앉아 보세요.` 강조색을 어두운 올리브(`#4f5f28`)로 조정해 약 6.19:1로 보정함.
- 원래 계산기 밝은 배경(`#e7e6df`) 위 베이지 강조색(`#b08e74`)의 대비는 약 2.41:1로 낮았음. `미리 그려 보세요.` 강조색을 어두운 브라운(`#70543f`)으로 조정해 약 5.54:1로 보정함.
- 확인 모달의 `선택 수정하기`는 `prefers-reduced-motion: reduce`일 때 `scrollIntoView({ behavior: 'auto' })`를 사용하고, 그 외에는 `smooth`를 사용하도록 실제 JavaScript 조건을 확인함.

## 실제 검증

검증 스크립트: `verify.cjs`
실행 명령: `node examples/v2.2.5-pccafe-comparison/control/verify.cjs`
실행 환경: 로컬 정적 서버 `http://127.0.0.1:8835/control/`, Playwright Chromium, 데스크톱 1440×1000 및 모바일 390×844

- 히어로 이미지 로딩, 데스크톱 및 모바일 수평 넘침, 런타임 오류 확인
- 세 좌석과 1, 2, 3시간 조합 전체 9개 요금 계산 확인
- 방문 계획 확인 대화상자 열기, 선택값 표시, 선택 수정하기로 닫기 확인
- 모바일 메뉴 열기와 앵커 이동 후 닫기 확인
- 터치 좌석 및 시간 선택으로 요금 갱신 확인
- 포인터 호버 후 이탈 동작 확인
- 포커스 가능한 버튼과 링크, `Escape` 닫기, 좌석·시간 라디오 그룹의 방향키 이동을 구현함
