# NOON PC 히어로 이미지 업데이트 시각 목표

- 기록 시각: 2026-08-05T10:15:50+09:00
- 대상: PC방 프랜차이즈 가맹 검토 랜딩 페이지의 첫 화면
- 사용자 요구: 이미지 생성 도구로 브랜드에 맞는 히어로 이미지를 만들고 실제 히어로 영역에 통합

## 시각 방향

- 실제 가맹 희망자가 매장 분위기와 운영 설계를 동시에 판단할 수 있는 상업 공간 이미지
- 검정·차콜 기반 공간에 절제된 라임 포인트를 사용하고 무지개 RGB, 사이버펑크 안개, 과도한 네온은 배제
- 좌석 밀도, 중앙 통로, 팀룸, 천장 흡배기와 케이블 정리가 읽히는 현실적인 한국형 PC방
- 사람이나 로고, 읽을 수 있는 모니터 UI 없이 공간 자체를 주인공으로 구성

## 히어로 통합 기준

- 생성 이미지는 우측 설계 패널 상단에 배치하고 기존 좌석 평면도는 판단 도구로 유지
- 이미지는 장식이 아니라 60평 모델의 좌석 존과 운영 동선을 설명하는 시각 자료로 사용
- 데스크톱에서는 공간 사진과 설계도가 한 화면의 연속된 편집 패널로 보여야 함
- 모바일에서는 사진, 모델 정보, 평면도 순으로 자연스럽게 쌓이고 가로 스크롤이나 잘림이 없어야 함
- 새로 추가되는 사용자 노출 문구는 존댓말 또는 명사형 단답만 사용

## 검증 계획

- 1440px 데스크톱과 390px 모바일 첫 화면 캡처
- 1차 캡처에서 이미지 크롭, 텍스트 대비, 평면도 가독성을 점검한 뒤 최소 한 번 수정
- 모델 전환과 상담 신청 흐름이 이미지 통합 후에도 유지되는지 확인
- Lighthouse와 Genscaff 품질 검증을 다시 실행
