# Design Signals

Use these as quality signals, not as permission to copy brand assets, layouts, trademarks, or proprietary expression.

Read `brand-visual-research.md` for the live-site observations behind these signals.

## Premium Reference Patterns

- Apple: one product dominates the viewport; centered type and product imagery create calm hierarchy; primary actions are few and obvious.
- Airbnb: search and object cards dominate; real photos, price/rating metadata, and repeated card rhythm make browsing concrete.
- Netflix: media is the environment; dark overlay, oversized title, email action, and red CTA create immediate entertainment conversion.
- Stripe: technical copy carries the page; strong navigation, precise CTAs, business proof, and controlled color energy support clarity.
- Linear: actual product UI is the hero proof; dark restrained surfaces, dense UI details, and muted copy sell operational seriousness.
- Vercel: sparse monochrome composition, strong symbol, short action pair, and customer proof create developer-platform confidence.
- Notion: calm workspace density, readable hierarchy, flexible content blocks, useful empty states, human but not childish tone.

## Direction Selection

Choose the reference pattern that fits the product:

- Consumer product: prioritize clarity, trust, imagery, and emotional warmth.
- SaaS or dashboard: prioritize scanability, density, action clarity, and predictable navigation.
- Developer tool: prioritize precision, code readability, docs quality, keyboard-friendly flows, and restrained styling.
- Media or entertainment: prioritize immersive assets, browsing flow, strong hierarchy, and motion discipline.
- Premium brand or portfolio: prioritize asset quality, editorial pacing, typography, and focused composition.

## High-End Visual Markers

- The first viewport immediately communicates the product, brand, or task.
- The first viewport contains a real product, workflow, place, content, or object signal; abstract decoration alone fails.
- The product remains identifiable when its name, logo, and accent color are removed because domain objects, language, data, decisions, and workflow states remain.
- The primary CTA predicts a product-specific result and the interaction visibly reaches that result or a stable next step.
- The main surface helps the user make or complete a real decision instead of only reading positioning copy.
- Typography has visible hierarchy without using oversized text everywhere.
- Spacing follows a clear rhythm. Related things are close; unrelated things breathe.
- Color is functional: action, status, grouping, hierarchy, and brand mood are distinct.
- Components feel designed as a system, not assembled from unrelated snippets.
- Mobile is intentionally composed, not a squeezed desktop layout.
- Motion supports causality and feedback; it never hides layout weakness.
- Empty, loading, error, and disabled states feel like part of the same product.

## Common Premium Layout Moves

- Use a strong primary surface and fewer secondary panels.
- Align edges across nav, content, and controls.
- Create contrast through scale, weight, tone, and proximity instead of decoration.
- Use one memorable visual anchor: product image, data view, media, map, canvas, or live preview.
- Make repeated items scannable with consistent metadata order.
- Keep control groups stable in size so state changes do not shift layout.
- Let the next section peek into the first viewport when a landing page needs scroll momentum.
- Use brand references by matching problem structure, not visual costume: marketplace grids for browse tasks, product screenshots for software, cinematic media for entertainment, sparse symbols for platform identity.
- Derive screen and section topology from the user's task and domain content before applying a familiar marketing composition.

## Product Signature Signals

Use several independent signals rather than styling alone:

- Real domain objects and realistic attributes.
- Target-user vocabulary and units.
- A category-specific decision with relevant inputs and consequences.
- Workflow states tied to the task.
- Representative media, records, data, inventory, or user-created content.
- Constraints such as availability, compatibility, permission, eligibility, capability, or delivery state.

Name, logo, accent color, generic metrics, and a renamed card grid do not count as a product signature.

Run the two-domain substitution test from `product-specificity-and-action-gate.md`. If superficial relabeling still works, the result is conventional rather than product-specific.

## Copy Tone

Use specific product language. Replace generic claims with concrete nouns, verbs, and outcomes.

Avoid:

- "Experience the future of..."
- "Unlock your potential..."
- "Seamlessly transform..."
- "Beautiful and intuitive..."
- "AI-powered solution for everything..."

Prefer:

- Clear object: what the product is.
- Clear action: what the user can do.
- Clear result: what changes after use.
- Clear consequence: what a choice affects.
- Clear recovery: how the user corrects or retries when needed.
