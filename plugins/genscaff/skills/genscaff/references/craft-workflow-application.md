# Workflow Application Craft

## Selection

Select when returning users monitor, edit, or act on operational data. Do not select for passive reading or one bounded transaction.

## Craft

- Put task and action hierarchy before decorative dashboard chrome.
- Keep tables, filters, bulk actions, permissions, and persistent state explicit.
- Cover real loading, partial, empty, error, and recovery paths.
- Preserve dense scanability while collapsing deliberately on small containers.
- Confirm destructive actions proportionally and keep common keyboard work efficient.

Typical patterns include summary exceptions, filters, data views, detail panels, action feedback, and permission states. Risks include inaccessible grids, lost filter state, hidden actions, stale data, and mobile card duplication. Verify primary operations, persistence, permissions, relevant states, responsive collapse, keyboard/focus, status announcements, and data density.

Do not clone a fashionable admin shell or replace established project navigation for visual convenience.
