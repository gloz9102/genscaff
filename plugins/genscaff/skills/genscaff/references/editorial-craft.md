# Editorial Craft

Use this after the router selects Editorial / content. Preserve the publication's voice, hierarchy, and source conventions.

## Checks

- Keep line length, type size, and spacing suitable for sustained reading in the target language.
- Provide headings, landmarks, and local navigation that match the document's real structure.
- Keep sources, dates, authorship, captions, and update status close to the relevant content.
- Make tables, code, media, footnotes, and long tokens readable without horizontal page overflow.
- Distinguish navigation, metadata, primary content, related material, and promotion by hierarchy rather than card decoration alone.
- Preserve reading position and context after expanding, filtering, or following in-page navigation.
- Handle missing media, long headings, translated copy, and narrow mobile widths.
- Keep calls to action from interrupting the primary reading task without evidence of editorial intent.

## Outcome gate

Score reading flow, navigation, source clarity, long-content resilience, and mobile readability from 0 to 5 using `workflow-rubric.md`. Revise only dimensions below 3.
