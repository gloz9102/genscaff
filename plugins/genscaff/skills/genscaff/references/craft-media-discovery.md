# Media Discovery Craft

## Selection

Select when users browse meaningful content groups, resume progress, and choose media. Do not select merely because a page is dark or contains cards.

## Craft

- Group content by user meaning; balance high density with readable metadata.
- Choose rails only when horizontal grouping helps discovery; otherwise use a grid or vertical list.
- Preserve progress, unavailable/restricted, and slow/missing/broken poster states.
- Treat preview and autoplay as optional, constrained behavior with explicit controls and reduced-motion fallbacks.
- Prefer vertical discovery on narrow screens unless horizontal movement remains usable and obvious.

Arrow-key behavior is required only for composite widgets that adopt it. In every horizontally scrollable region, keep focused items visible and provide a non-drag path. Evaluate image loading, layout stability, list size, and virtualization from measured need. Verify grouping, selection flow, progress, poster failures, mobile layout, complete keyboard path, focus visibility, and reduced motion.

Do not copy Netflix branding, exact rails, navigation, poster proportions, proprietary media/type, or preview sequence.
