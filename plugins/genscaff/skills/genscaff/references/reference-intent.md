# Reference Intent

Classify every supplied image, mockup, or named product before deriving a visual target. Record the mode, scope, rationale, and conflicts.

## Locked reproduction

Use only when the user explicitly requests exact reproduction, identifies the locked scope, and represents that supplied assets may be used. Record locked text, order, labels, relationships, media placement, adjustable details, and responsive/accessibility conflicts. An attachment alone does not select this mode.

## Structural reference

Preserve information hierarchy, component relationships, primary behavior, content order, and task flow. Adapt responsive composition, treatment, spacing, exact dimensions, component count, secondary copy, and implementation technique to the project.

## Aesthetic inspiration

Default named-site or brand-style requests here. Extract information hierarchy, density, discovery model, interaction rhythm, spacing and typography roles, media strategy, responsive behavior, accessibility expectations, and performance expectations.

For each reference record:

- three to five `adopted_principles`
- `product_fit_rationale` for each principle
- at least three `deliberate_differences`
- `excluded_from_copying`
- `repository_derived_elements`

Do not copy logos, trademarks, proprietary copy, copyrighted imagery, exact composition, card geometry, navigation, unique interaction sequence, proprietary iconography, or distinctive brand color combinations.

Apple-like does not mean black backgrounds and giant type; test whether product narrative is the task. Airbnb-like does not mean rounded cards; test search, comparison, availability, and trust. Netflix-like does not mean dark rails; test content grouping, density, progress, and focus-aware discovery.

## No reference

Derive the target from user requirements and repository evidence. Do not invent a fashionable reference after the fact.

## Generated images

Generate a mockup first only for an explicit mockup-first workflow. A request for one image asset does not imply a page mockup. Treat generated work through the same modes and never call it an official brand asset or a user-owned source asset.
