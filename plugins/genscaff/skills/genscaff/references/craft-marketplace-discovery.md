# Marketplace Discovery Craft

## Selection

Select when users search, filter, compare, assess availability/trust, and choose among offers. Do not select for a single editorial product story or a transaction after the choice is already made.

## Craft

- Make search primary when it advances the real job; keep applied filters observable and reversible.
- Build comparison-ready cards with distinct roles for price, location, availability, rating, and trust.
- Use safe defaults and avoid fabricated selection steps.
- Support no results, unavailable or changed inventory, partial data, missing media, and long location names.
- Use a mobile filter pattern that preserves applied state and result context.

Keyboard-operable filters and an accessible date picker are required when present. Keep focus visible through result updates and announce meaningful dynamic changes. Watch large result payloads, image stability, filter latency, and unnecessary map/media work. Verify search-to-choice flow, applied-state feedback, no-results/recovery, partial/missing data, mobile filters, and keyboard/focus.

Do not copy Airbnb branding, search-bar geometry, card proportions, icons, real listing data, or booking interactions.
